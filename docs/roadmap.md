# Roadmap

This roadmap lists possible future work. It is not a promise that these features already exist.

## v0.1.x

- Add more schema templates for tensile tests, heat treatment, XRD, and coating tests.
- Add more Japanese alias dictionaries for common materials experiment columns.
- Add optional schema warnings for suspicious unit combinations.
- Add Markdown report output for support requests.

## Later Candidates

- Optional unit conversion for a small, documented set of units.
- More `.xlsx` layout support for simple two-row headers.
- Integration examples for pandas, R, and materials informatics workflows.
- Project-level schema packs contributed by users.

## Out Of Scope For Now

- PDF/OCR extraction.
- LLM-based inference.
- Full ELN/LIMS replacement.
- Quality assurance pass/fail certification.
- Proprietary standard text or regulated compliance claims.
