# Code Of Conduct

This project is small, but contributions and issue reports should stay respectful,
practical, and safe for public discussion.

## Expected Behavior

- Be specific and factual when reporting problems.
- Assume sample data may contain sensitive experiment or customer context.
- Keep reviews focused on code, documentation, tests, and reproducible behavior.
- Disagree by explaining the technical reason and a concrete alternative.

## Unacceptable Behavior

- Harassment, personal attacks, or discriminatory language.
- Posting confidential experiment data, customer names, real lot numbers, internal
  material codes, or unpublished measurements.
- Claiming project adoption, compliance, or scientific validation without public
  and verifiable evidence.

## Reporting

For ordinary behavior issues, open a GitHub issue with only the minimum public
context needed. If the report includes sensitive information, do not post it
publicly; ask for a private contact path in a minimal public issue.

Maintainers may edit, hide, or remove public content that exposes confidential
data or creates an avoidable safety/privacy risk.
