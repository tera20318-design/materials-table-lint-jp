# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-06-02

### Added

- Initial `mtlint` CLI.
- CSV input with `# key=value` metadata comments.
- Optional `.xlsx` input through `openpyxl`.
- JSON schema-based column aliases, unit checks, required metadata, uniqueness, numeric parsing, and range checks.
- `init`, `inspect`, `lint`, and `normalize` commands.
- Human-readable CLI summaries, normalized CSV output, and JSON reports.
- Tests, GitHub Actions CI, examples, and OSS documentation.
